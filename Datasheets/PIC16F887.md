# PIC16F887 - Datos Verificados del Datasheet (Microchip DS41291F)

## Información General
- **Fabricante:** Microchip Technology
- **Familia:** PIC16F, 8-bit RISC
- **Instrucciones:** 35 instrucciones de palabra única
- **Stack hardware:** 8 niveles
- **Tecnología:** CMOS nanoWatt, Flash

## Memoria
- **Flash (programa):** 8192 × 14 bits ≈ 14 KB
- **SRAM (datos):** 368 bytes
- **EEPROM datos:** 256 bytes

## I/O y Periféricos
- **Pines I/O:** 35 (Puertos A, B, C, D, E)
- **ADC:** 10 bits, 14 canales (AN0-AN13)
  - VREF+/VREF- programables
  - Canal 0 = RA0/AN0 (pin 2)
  - Canal 1 = RA1/AN1 (pin 3)
  - Canal 2 = RA2/AN2 (pin 4)
- **Comunicación:**
  - 1 EUSART (UART con Auto-Baud y Auto-Wake)
    - TX/CK = RC6 (pin 25)
    - RX/DT = RC7 (pin 26)
  - 1 MSSP (SPI + I2C master/slave)
- **Temporizadores:** Timer0, Timer1, Timer2
- **Interrupciones:**
  - INT externo en RB0/INT (pin 33)
  - Interrupción por cambio en RB4-RB7
  - Interrupciones ADC, Timer, UART, etc.

## Reloj
- **Rango externo:** DC – 20 MHz (cristal/oscilador)
- **Oscilador interno:** 8 MHz – 31 kHz calibrado
- **Modo LP (Low Power):** Cristal 32.768 kHz en RA6/RA7 (pines 14/13)
  - Capacitores 15pF a masa en cada pin
  - Configuración fusibles: LP

## Alimentación
- **VDD:** 2.0V – 5.5V
- **Pines VDD:** 11, 32
- **Pines VSS:** 12, 31
- **Desacople:** 100nF cerámico en cada par VDD/VSS

## Empaque
- **DIP-40 (PDIP)** - Paso 2.54mm, ancho 7.62mm (0.300")
- **También disponible:** 44-QFN, 44-TQFP

## ADC - Cálculos para DK Energy
- **Referencia:** VDD = 5.0V (VDD conectado a riel 5V del MT3608)
- **Resolución:** 10 bits = 1024 pasos
- **LSB:** 5.0V / 1024 = 4.88 mV/paso

### Tensión Batería (RA0/AN0)
- Divisor: 10kΩ / 10kΩ entre B+ y OUT- (GND del sistema)
- Factor división: 2 (Vin = 2 × Vadc)
- Rango batería: 3.0V - 4.2V → ADC: 614 - 860
- Fórmula: `mV_bat = adc × 10000 / 1023` (en milivoltios)

### Tensión Panel (RA1/AN1)
- Divisor: 10kΩ / 10kΩ
- Factor división: 2
- Rango panel: 0V - 5.5V → ADC: 0 - 1126 (satura a 1023 = 5V)
- Fórmula: `dV_panel = adc × 100 / 1023` (en décimas de voltio)

### Corriente Descarga (RA2/AN2)
- Shunt: 0.1Ω en riel GND (baja lado)
- Amplificador: LM393 no inversor, ganancia 48 (1 + 470k/10k)
- Salida colector abierto + pull-up 1kΩ a VCC
- Offset ±5mV = ±50mA error → CALIBRAR CON CARGA CERO
- Fórmula: `cA = (adc × 50000 / 49104) / 10` (centésimas de Ampere)

## Sleep Mode (LP Oscilador)
```c
// Al apagar sistema (botón suelto):
setup_adc(ADC_OFF);           // Apagar ADC
ext_int_edge(H_TO_L);         // Flanco descendente en RB0
enable_interrupts(INT_EXT);   // Habilitar INT externo
enable_interrupts(GLOBAL);    // GIE=1
sleep();                      // Entrar en sleep
// Despierta por flanco descendente en RB0 (botón encendido)
// Al despertar: continúa siguiente instrucción tras sleep()
// GIE se mantiene en 1, no hace falta ISR si solo se usa para despertar
```

## Consideraciones Importantes
1. **NOMCLR:** MCLR (pin 1) libre para I/O, pero dejar conector ICSP para programación
2. **RB0/INT:** Único pin con interrupción externa real. Para wake-up de sleep.
3. **RB4-RB7:** Interrupción por cambio (IOC). Si botón teléfono (B.C) debe despertar, mover a RB4-RB7.
4. **RA6/RA7:** Solo para oscilador LP. NO usar como I/O normal cuando LP activo.
5. **VDD/VSS:** Desacoplar CADA par con 100nF cerámico lo más cerca posible del pin.
6. **LCD RW (pin 21):** Conectar a GND para modo solo escritura (ahorra 1 pin).
